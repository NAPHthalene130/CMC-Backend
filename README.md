# CMC-Backend

Contract Management System Backend

## Tech Stack

- Spring Boot 3.2
- MyBatis-Plus 3.5
- Sa-Token (Authentication & Authorization)
- MySQL 8.x + Redis
- EasyExcel (Export)
- Knife4j (API Documentation)
- Spring AOP (Operation Logging)

## Getting Started

```bash
# Start MySQL & Redis first, then:
mvn spring-boot:run
```

API Docs: http://localhost:8080/doc.html
